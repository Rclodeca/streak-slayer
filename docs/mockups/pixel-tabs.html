Pixel-cut · Skills / Quests tabs

Four ways to show one list at a time instead of one long scroll. Every phone is live: tap the tabs, strike skills, check off quests, scroll the lists, and swipe in D. The stage stays pinned as shipped.

Rules every option follows
  • Resist lives inside the Skills tab, under Weekly, as now. It is quiet and only matters when you give in.
  • Opens on Skills every time (the daily loop is checking skills). It does not remember the last tab, the same as Main/Side today.
  • Quests keeps its Main / Side switch inside the tab, drawn as plain underlined text so it never reads as a second row of tabs.
  • The add button follows the tab: "+ New habit" on Skills, "+ New task" on Quests (Side has none, as now). The first-habit spotlight still points at it on Skills.
  • Tabs carry a count so you can tell what is left without switching: struck today on Skills, quests due soon on Quests.
  • Sealed Quests (level under 3): the tab stays, shows a lock, and opens the existing "Sealed until level 3" seal. Toggle it below.

TASKS · B + P2

Coloured groups with the six fixed slots you can rename. Type a new name in the third phone and it updates the other two. Tap chips to filter, boxes to check off.

1 · Tasks tab

Chips only for groups that have tasks, so the row stays short. The pencil at the end opens Groups. Tasks with no group show under All only.

2 · New task

Group is optional: tap one to pick it, tap it again to clear. "Rename groups" opens the third phone. Difficulty stays in the form (it sets the EXP), just not on the card.

3 · Groups

Six slots, fixed icon and colour, name editable. No adding, deleting or reordering. A cleared name goes back to the default.

  • Fixed per slot: icon and colour never change, so a renamed slot keeps its look (renaming Other to "Side project" keeps the sparkles).
  • Names: up to about 14 characters so they fit a chip and a 3-column grid on a phone.
  • Saved data: each task stores the slot id (work, home...), not the name, so renaming never moves a task.
